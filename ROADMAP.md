# Roadmap

This project should grow from real Codex Desktop failure evidence, not from guessed feature lists.

## Current Focus

- Windows Codex Desktop.
- Chrome plugin diagnosis.
- Computer Use diagnosis.
- Bundled plugin cache and marketplace mirror failures.
- Current-thread capability loading problems when plugin settings look correct.

## Near-Term v0.2.x

- Expand the evidence pattern catalog with real sanitized reports.
- Maintain the read-only health report helper as new safe evidence fields are identified.
- Maintain the small version matrix for observed Codex Desktop builds and bundled plugin paths.
- Improve issue templates based on user reports.
- Add more examples for failed validation and inconclusive diagnosis.
- Keep the skill itself concise and move detailed material into reference files.

## Later v0.3.x

- Consider reversible repair helpers only after repeated cases and rollback testing.
- Consider additional Codex Desktop plugin surfaces only when there is a real validation method.

## Non-Goals For Now

- General Windows cleanup.
- Deleting or rebuilding the entire `.codex` directory.
- Billing, account, model selection, or subscription support.
- GitHub, Gmail, Drive, Photoshop, Cloudflare, or other connector diagnosis without repeated evidence.
- Fake issues, fake logs, or artificial activity meant to inflate project importance.
